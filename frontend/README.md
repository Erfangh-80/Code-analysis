# Frontend

رابط کاربری فارسی و RTL پروژهٔ **Code Risk Analyzer** با React، TypeScript و Vite ساخته شده است. این نسخه نمایهٔ فازهای ۱ تا ۴ است: یک «هستهٔ تحلیل» تک‌صفحه‌ای که تحلیل ایستا، تحلیل تاریخچهٔ Git و امتیاز Hotspot را مستقیماً از API محلی می‌خواهد. هیچ مسیر پروژه یا کد منبعی به سرویس خارجی ارسال نمی‌شود و هیچ داشبورد، گزارش ذخیره‌شده یا خروجی فایل در این نسخه وجود ندارد.

## فناوری‌ها و معماری

- React 19 + TypeScript + Vite
- Tailwind CSS v4 و design tokenهای قابل استفاده مجدد در `src/styles/globals.css`
- کامپوننت‌های پایهٔ shadcn/ui در `src/components/ui`
- React Router برای مسیر `/` و صفحهٔ not-found
- TanStack Query برای درخواست‌ها و مدیریت وضعیت mutation
- Zustand برای state رابط کاربری (مانند sidebar موبایل و حالت روشن/تاریک)
- ساختار Atomic Design:
  - `components/atoms` برای اجزای هویتی کوچک
  - `components/molecules` برای ترکیب‌های کوچک UI
  - `components/organisms` برای sidebar و header
  - `components/templates` برای shell اصلی
  - `features/core` برای صفحهٔ هستهٔ تحلیل

## اجرا

ابتدا API محلی Go را از پوشهٔ `../backend` اجرا کنید. سپس:

```bash
cd frontend
npm install
npm run dev
```

Vite روی همهٔ interfaceها bind می‌شود. مسیرهای نسبی `/api/...` در dev server به `http://127.0.0.1:8080` proxy می‌شوند. کد مرورگر فقط از مسیرهای نسبی مانند `/api/v1/static-analysis` استفاده می‌کند و به `localhost` یا سرویس خارجی درخواست مستقیم نمی‌فرستد.

## مسیرهای فعلی

| مسیر | کاربرد |
| --- | --- |
| `/` | هستهٔ تحلیل: سه گام تحلیل ایستا، تحلیل Git و امتیاز Hotspot به‌علاوهٔ وضعیت اتصال سرویس محلی |
| هر مسیر دیگر | صفحهٔ not-found با پیوند بازگشت |

## گردش کار هستهٔ تحلیل

1. **تحلیل ایستا** — مسیر مطلق root محلی و فهرست مسیرهای نسبی فایل‌های `.go`، `.js`/`.mjs`/`.cjs` یا `.py` به `POST /api/v1/static-analysis` فرستاده می‌شود و نتیجهٔ فایل‌ها/ماژول‌ها همان‌طور که از API آمده نمایش داده می‌شود.
2. **تحلیل تاریخچهٔ Git (اختیاری)** — مسیر worktree محلی و بازهٔ زمانی اختیاری به `POST /api/v1/git-analysis` فرستاده می‌شود؛ فقط خواندنی است و مخزن را تغییر نمی‌دهد.
3. **امتیاز Hotspot** — صفحه ورودی‌های score را از نتایج برگشتی API می‌سازد و با `POST /api/v1/risk-analysis` از backend می‌خواهد امتیاز، رتبه و contributionها را محاسبه کند.

مرورگر هیچ metric، نرمال‌سازی، امتیاز، band، رتبه یا تجمیع ماژولی را خودش محاسبه نمی‌کند؛ فقط پاسخ API را render می‌کند. نتایج فقط در حافظهٔ صفحهٔ فعلی نگه داشته می‌شوند و با refresh از بین می‌روند؛ این رفتار در این نسخه عمدی است.

تمام داده‌های نمایش‌داده‌شده از API واقعی می‌آیند؛ صفحه دادهٔ نمونه یا نتیجهٔ ساختگی نشان نمی‌دهد. خطاهای render با `errorElement` به صفحه‌ای قابل‌اقدام تبدیل می‌شوند و خطاهای API با پیام امن و قابل‌فهم نمایش داده می‌شوند.

## کیفیت

```bash
npm run typecheck
npm test
npm run build
```

تست‌ها انتقال نسبی `/api`، رندر مستقیم پاسخ تحلیل ایستا، و نبود محاسبهٔ امتیاز در مرورگر را پوشش می‌دهند.
